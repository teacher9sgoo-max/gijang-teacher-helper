# 기장중학교 교무 도우미 온라인 공개 및 Windows 설치 안내

## 먼저 알아둘 점

다른 선생님들이 링크를 눌러 접속하려면 `index.html` 파일을 인터넷의 **HTTPS 주소**에 올려야 합니다. 현재 파일을 컴퓨터에서 더블클릭해 여는 `file://` 방식은 다른 사람과 공유하는 온라인 주소가 아니며, PWA 설치와 자동 시작 기능도 제한됩니다.

가장 쉬운 방법은 정적 파일 호스팅 서비스에 아래 파일을 한 폴더째 올리는 것입니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 교무 도우미 본체 |
| `manifest.webmanifest` | Windows 설치형 앱 이름·색상·실행 설정 |
| `sw.js` | 앱 셸 캐시 |
| `dashboard-config.js` | 선택 설정 파일 |
| `icons/icon-192.svg` | 앱 아이콘 |
| `icons/icon-512.svg` | 고해상도 앱 아이콘 |

## 1단계: 온라인 주소 만들기

GitHub 계정이 있다면 새 저장소를 만들고 이 폴더의 파일을 업로드합니다. 저장소의 `Settings → Pages`에서 배포 대상을 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/root`로 선택하고 저장합니다. 잠시 뒤 다음과 같은 주소가 생깁니다.

`https://깃허브아이디.github.io/저장소이름/`

주소가 열리는지 먼저 확인합니다. 첫 화면이 정상적으로 열리고 구글 시트 데이터가 불러와지면 이 주소가 선생님들에게 공유할 공식 링크입니다. 저장소가 비공개이면 다른 선생님들이 접근하지 못할 수 있으므로 공개 저장소 또는 공개 정적 호스팅을 사용해야 합니다.

GitHub Pages를 사용하지 않는다면 Netlify, Cloudflare Pages 등 정적 HTTPS 호스팅에 동일한 폴더를 업로드해도 됩니다. 중요한 것은 `index.html`, `manifest.webmanifest`, `sw.js`, `dashboard-config.js`, `icons` 폴더를 같은 구조로 올리는 것입니다.

## 2단계: 링크 공유

온라인 주소가 만들어진 뒤 교무 도우미 상단의 **링크 공유** 버튼을 누르면 모바일에서는 공유 창이 열리고, 공유 기능이 없는 브라우저에서는 주소가 클립보드에 복사됩니다. 복사한 주소를 교사 단체방에 보내면 됩니다.

## 3단계: Windows에 설치

선생님은 공유받은 HTTPS 링크를 Edge 또는 Chrome에서 엽니다. 주소창 오른쪽의 설치 아이콘 또는 화면 상단의 **앱 설치** 버튼을 누르고 설치를 승인합니다. 설치가 끝나면 바탕화면이나 시작 메뉴에서 `기장중학교 교무 도우미`를 별도 앱처럼 실행할 수 있습니다.

현재 브라우저가 설치 버튼을 보여주지 않는다면 `file://` 파일로 연 것이거나 HTTPS가 아닌 주소일 가능성이 큽니다. 반드시 1단계에서 만든 HTTPS 공유 링크를 사용해야 합니다.

## 4단계: Windows 시작 시 자동 실행

앱 상단의 **자동 시작 설정** 버튼을 누르고 **시작 아이콘 다운로드**를 선택합니다. 다운로드한 `.url` 파일을 다음 위치에 넣습니다.

1. `Win + R`을 누릅니다.
2. `shell:startup`을 입력하고 Enter를 누릅니다.
3. 다운로드한 `기장중학교-교무도우미-자동시작.url` 파일을 열린 폴더에 넣습니다.
4. 다음 Windows 로그인부터 교무 도우미가 자동으로 열립니다.

자동 실행을 중지하려면 같은 시작프로그램 폴더에서 해당 `.url` 파일을 삭제하면 됩니다. 이 방식은 웹페이지가 Windows 시스템 폴더에 몰래 접근하지 않고, 사용자가 직접 승인하는 안전한 방식입니다.

## 5단계: 관리자 확인 사항

구글 시트와 Apps Script 웹앱 주소는 기존 설정을 그대로 사용합니다. 다른 교사에게 링크만 공유해도 회원 명부와 시간표가 공개되는 것이 아니라, 교사 아이디와 비밀번호로 로그인해야 기존 기능을 사용할 수 있습니다. Apps Script의 배포 권한은 기존 회원·시간표 연동이 정상 동작하는 설정을 유지해야 합니다.

## 문제가 생길 때 확인할 것

| 증상 | 확인할 사항 |
|---|---|
| 링크가 열리지 않음 | 배포 주소가 HTTPS인지, 저장소가 공개인지 확인 |
| 앱 설치 버튼이 없음 | HTTPS 주소로 접속했는지 확인 |
| 화면은 열리지만 시트가 비어 있음 | 구글 시트 공유 권한과 Apps Script 배포 상태 확인 |
| 자동 시작 파일이 실행되지 않음 | `.url` 파일이 `shell:startup` 폴더 안에 있는지 확인 |
| 다른 교사가 로그인하지 못함 | ‘교사 아이디 비번’ 시트의 아이디·비밀번호 확인 |
