학생 뽑기

대상 학생 수: -
학년·반·인원을 선택하고 뽑기 버튼을 눌러주세요.

자리 뽑기

대상 학생 수: -
틀을 만든 뒤, 자리를 클릭하면 학생을 직접 지정하거나 ✕로 제외할 수 있어요. 제외/지정한 자리를 뺀 나머지에 ② 무작위 배치를 적용하세요.
학년·반과 행·열 수를 정하고 "빈 자리 틀 만들기"를 눌러주세요.

모둠 뽑기

대상 학생 수: -
학년·반과 편성 방식을 선택하고 모둠 편성 버튼을 눌러주세요.

수업 진도 기록

기록은 이 기기에 즉시 저장되고, 연결된 구글 시트의 ‘수업 진도’ 탭에도 함께 전송됩니다. 해당 시트가 없으면 자동으로 만들어집니다. 화면 초기화는 선택 상태만 지우며 저장된 기록은 삭제하지 않습니다.
학년·반·교과를 선택하면 기록이 표시됩니다.

명렬 보기

대상 학생 수: -
1~19번은 남학생, 21번부터는 여학생으로 자동 구분해서 보여드려요.
학년과 반을 선택하면 명렬이 표시됩니다.

학생 활동 기록

이 기록은 로그인한 교사별로 따로 저장되며, ✕ 버튼(확인 후)으로 직접 지우지 않는 한 계속 남아있어요. "화면 초기화"는 화면 선택만 지울 뿐 기록은 그대로예요.
학년·반·학생을 선택하면 기록이 표시됩니다.

시간표 캐시

구글 스프레드시트에 저장된 최신 컴시간 시간표 캐시입니다. 탭을 열거나 새로고침을 누르면 시트 내용을 다시 읽습니다.

▣ 시간표 캐시 시트 열기 시간표 캐시를 불러오는 중입니다.
이 메뉴는 Apps Script가 이미 저장한 시간표 캐시를 다시 읽어 표시합니다. 컴시간 원본 수집과 30분 자동 갱신은 Apps Script의 createTimetableTrigger()가 담당합니다.
시간표 캐시를 불러오는 중입니다.

회원 명부 관리

구글 시트 ‘교사 아이디 비번’ 탭의 계정이 로그인에 사용됩니다.

안내: 회원 명부는 구글 스프레드시트의 ‘교사 아이디 비번’ 시트에서 자동으로 읽습니다. 로그인 창에서 ‘이 기기에서 자동 로그인 유지’를 선택하면 현재 로그인 정보만 이 브라우저에 기억해 다음 접속 때 자동 로그인합니다.

무료 시간표 서버 연결

스프레드시트에서 배포한 웹 주소(`/exec`)를 한 번 저장하면, 교사 시간표 탭에서 로그인 교사의 표를 자동으로 불러옵니다.

Windows EXE 설치파일

Windows용 설치파일을 내려받아 설치하면 바탕화면·시작 메뉴에서 교무 도우미를 앱처럼 실행할 수 있습니다.

  1. 아래 Windows EXE 설치파일 받기를 누릅니다.
  2. GitHub Releases에서 최신 Setup 설치파일을 내려받습니다.
  3. 설치 중 바탕화면·시작 메뉴 바로가기를 선택합니다.

자동 시작 설정

이 기능은 설치된 Windows EXE 앱에서만 작동합니다. 웹사이트에서는 Windows 시작 프로그램을 변경할 수 없습니다.
